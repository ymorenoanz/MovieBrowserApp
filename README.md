MovieBrowserApp

A modern application built with Jetpack Compose that fetches a list of movies using TMDB API.

Features: 
-  Fetch popular movies
- Display movies
- Loading state
- Error handling

Tech stack:
- Kotlin
- Coil for images
- Retrofit and GSON
- Jetpack Compose

Architecture:
- Clean architecture (Data/Domain/Presentation)
- MVVM Pattern
- Hilt for dependency injection

Future improvements:
- Detail screen
- Search
- Pagination
- Dark mode polish

Setup:
- Clone the repository
- Add your TMDB API key in gradle.properties
- Build and run
